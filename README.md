Entry for the [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty on [make.fun](https://make.fun).

## What it does

`main.ts` writes exactly one funny line to `/output/entry.txt` — a single joke that lands on a cold read, no setup notes, no explanation. The line is validated in-program against the bounty gate: 1–200 characters, not only white space, exactly one line, no control characters.

## Run

```sh
node main.ts
```

Honours `MAKEFUN_OUTPUT_DIR` / `OUTPUT_DIR` (default `/output`); refuses `.` as the output directory.
